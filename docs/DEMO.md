# Demo video script (target 6–7 minutes, hard limit 10)

Record at 1440×900 with the backend and frontend running. Prepare before recording:

```bash
./scripts/dev.sh                               # API + UI, both on free ports
# or, two terminals:
python -m backend.main                          # API on 8000, or the next free port
npm run dev                                     # UI on 5173, or the next free port
python -m scripts.make_demo_assets             # demo_assets/ ready for upload
```

Read the URLs both servers print: if another project already owns 8000/5173, Tutora
moves to the next free port (`./scripts/dev.sh --dry-run` shows the choice in advance).

## 0:00–0:40 — Problem and promise

*"Students study from lecture videos, textbooks and slides scattered across places. General
chatbots answer confidently without touching that material, and they ignore what the student
already knows. Tutora unifies the material into one cited knowledge base, refuses anything the
material does not cover, and models the learner topic by topic."*

Show the dashboard briefly: stats, topic mastery bars with evidence counts, recommendations.
Point at the sidebar badge: *offline mode* (or *Gemini: gemini-2.5-flash* if a key is set).

## 0:40–1:50 — Ingestion workflow (Library)

1. Click **Upload material** → choose `demo_assets/lecture_slides.pptx`. Show the new source
   with its slide count.
2. Upload `demo_assets/textbook_chapter.pdf` → point out that every unit kept its page number.
3. Upload `demo_assets/lecture_transcript.txt`, then paste a paragraph with **Paste notes**.
4. Click through units: each shows its exact origin (slide 2, page 3, paragraph 1) and its
   topic tag. If a key is configured, also upload `demo_assets/validation_curve.png` to show a
   figure being described and tagged — say explicitly that images need a key.

## 1:50–3:10 — Source-grounded tutor

1. Ask: **"How do I compute mean squared error?"** → grounded badge, verbatim excerpt, citation
   chip *slide 3*.
2. Click the citation → the Library opens the source, highlights the cited unit, and the PDF
   viewer opens at the exact page (`#page=n`).
3. Ask an off-material question: **"Who won the 2022 football World Cup?"** → *Declined — not
   in your material*, zero citations. Explain the BM25 threshold and that the model is never
   consulted for that query.
4. Mention the scope selector: answers can be restricted to one topic.

## 3:10–4:40 — Adaptive assessment

1. **Practice** → select two topics (or press **Diagnostic quiz** on the dashboard for the
   cold-start path) → set 5 questions, mixed types, adaptive difficulty → generate.
2. Show the tags on each question: topic, difficulty, type, origin (*reviewed bank* vs
   *AI-generated, verified*), and the collapsed source location.
3. Answer some correctly and some incorrectly, including a numerical item typed as `3.80`.
4. Submit → report: score, mastery deltas (`before → after` per topic), weak topics, likely
   misconceptions, and cited feedback for each question.
5. Generate another set and show that no question repeats (novelty is enforced by prompt hash;
   the API refuses with a clear message when the verified pool is exhausted).

## 4:40–5:40 — Learner model and course map

1. Back on the dashboard: mastery moved, evidence counts grew, recommendations re-ordered.
2. Emphasise the disclaimer: chat and reading never count as knowledge evidence.
3. Open **Course map**: prerequisites (supervised → regression → gradient descent → neural
   networks) with mastery colouring, and auto-grouped topics from uploads marked *auto*.

## 5:40–6:40 — Evaluation and architecture

1. Run in a terminal: `python -m evaluation.run` → read the metric block aloud
   (source hit 1.00, citation location 1.00, refusal 1.00, citation integrity 1.00, novelty 1.00).
2. Run `python -m evaluation.simulation --sessions 5` → mastery gains per simulated profile and
   the 0.000 repetition rate.
3. Be explicit about the honest limits: the local metrics are lexical; RAGAS/DeepEval/TruLens
   numbers are not reported because no judge key was available in this environment, and the
   adapter refuses to fabricate them; the simulated gains show model responsiveness, not human
   learning.
4. Show `docs/ARCHITECTURE.md` for 20 seconds: ingestion → units → BM25 → quiz generator →
   BKT learner model, plus the test suite (`20 passed`).

## 6:40–7:00 — Close

*"Tutora answers only from your material, cites the exact page, slide or timestamp, refuses the
rest, and adapts as you practise. Everything you saw is in the repository and reproducible with
the commands in the README."*
